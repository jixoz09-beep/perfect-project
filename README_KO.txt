2020~2026 사진 후보 연결

압축을 풀어 main.py와 CSV를 GitHub 저장소의 기존 main.py가 있는 위치에 올립니다. 기존 main.py를 교체하고 기존 data 폴더는 그대로 둡니다. requirements.txt는 바꿀 필요 없습니다.

CSV에는 후보 235건, 차량 ID 232개가 들어 있습니다. 기존 차량 ID와 연도가 정확히 같은 경우에만 사진 후보를 보여주며, 후보는 모두 검토 중이라고 표시합니다. 묶인 차량의 다른 ID나 다른 연식에는 자동으로 사진을 공유하지 않습니다. 기존 사진이 있으면 기존 사진을 우선 표시합니다. 원본 링크에서 촬영자·라이선스·이용 조건을 확인할 수 있습니다.

Commons 원본 링크의 전체 이미지 정상 표시, 차량 모델과 세대·페이스리프트, 전면 3/4 각도 및 라이선스는 일괄 재확인하지 않았습니다. 일부 링크는 표시되지 않을 수 있습니다. IONIQ 9과 EV4의 Commons 원본 페이지는 확인했습니다. 사진 파일 자체는 저장하지 않았습니다.
